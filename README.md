# Ybris

Jogo educativo desenvolvido para o **CIEE**, como parte do **Concurso Se Liga, Moçada! 2026**.

O projeto aborda a **violência contra a mulher** através de situações e perguntas que fazem o jogador refletir e identificar diferentes formas de violência.

## Sobre o jogo

Durante o jogo, são apresentadas diferentes situações. O jogador precisa analisar cada uma delas e decidir se existe uma situação de violência e qual é a sua classificação.

As respostas corretas geram pontos, enquanto os erros são contabilizados. Ao atingir **3 erros**, a pontuação da partida é zerada. O jogador pode acompanhar sua pontuação atual e sua melhor pontuação.

Pontuações acima de **1500 pontos** são enviadas para um **placar de líderes global**.

## Objetivo

O objetivo do projeto é utilizar um jogo como forma de informação e conscientização, tornando mais fácil reconhecer situações de violência contra a mulher e entender que ela pode acontecer de diferentes maneiras.
